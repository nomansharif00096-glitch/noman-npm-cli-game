# 🎯 JS Expert Quiz CLI

> A fun, interactive CLI trivia game testing your JavaScript knowledge! Answer all questions correctly to keep the process alive and win big. 🏆

## ⚡ Quick Start

Run the game directly in your terminal using `npx`—no installation required!

```bash
npx noman-cli-game
```

Alternatively, install it globally to play whenever you want:

```bash
npm install -g noman-cli-game
noman-cli-game
```

---

## 🎮 How to Play

1. Start the game using the CLI command.
2. Enter your name when prompted.
3. Answer multiple-choice questions about JavaScript core concepts.
4. **High Stakes:** You are controlling a Node.js process! Get **one answer wrong**, and the process gets **killed** (`process.exit(1)`). 💀
5. Get all questions right to reach the ultimate prize! 🎉

---

## ✨ Features

- **Interactive Prompts:** Simple, intuitive navigation using your keyboard arrow keys.
- **Colorful CLI UI:** Uses gradient text, animated banners, and ASCII banners.
- **Realistic Loading Spinners:** Real-time feedback for checking answers.
- **Instant Feedback:** Find out immediately if you survive or get eliminated.
